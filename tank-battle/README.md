# 🎮 坦克大战 (Tank Battle)

一个使用纯 HTML/CSS/JavaScript + Canvas 制作的网页坦克大战游戏。

## 🎯 游戏特色

- **流畅的 Canvas 渲染** - 60fps 丝滑体验
- **多种敌人类型** - 普通坦克、快速坦克、重型坦克、Boss
- **波次系统** - 消灭所有敌人后进入下一波，难度递增
- **可破坏地形** - 砖墙可被子弹摧毁，钢铁墙壁不可破坏
- **弹药系统** - 限弹量+主动换弹机制
- **粒子特效** - 爆炸、弹道轨迹等视觉效果
- **合成音效** - 基于 Web Audio API 的实时音效

## 🕹️ 操作方式

| 按键 | 功能 |
|------|------|
| **W A S D** | 移动坦克 |
| **鼠标** | 瞄准炮塔 |
| **鼠标左键 / 空格** | 发射炮弹 |
| **R** | 重新装填弹药 |
| **P** | 暂停 / 继续 |

## 🚀 快速开始

直接在浏览器中打开 `index.html` 即可开始游戏！

```bash
# 或者使用任意本地服务器
python -m http.server 8000
# 访问 http://localhost:8000
```
